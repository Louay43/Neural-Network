# Reproducing the artifacts

All metrics and figures in this directory were generated by executing the project.

| Path | Command | Purpose |
|---|---|---|
| `mnist/` | `python train.py` | Full 20-epoch run, final checkpoint, metrics, plots, test predictions |
| `evaluation/` | `python evaluate.py` | Independent reload and test evaluation of the saved checkpoint |
| `experiments/` | `python experiments.py` | Ten configurations, three seeds each, validation-only comparisons |
| `gradient_checks.json` | `python check_gradients.py` | Exhaustive checks on tiny ReLU and sigmoid networks, including L2 and inputs |
| `smoke/` | See the command in `smoke/run.json` | Earlier short pipeline execution check; not the headline result |

`run.json` records actual arguments, precision, seeds, library versions, partition sizes, and thread environment. `history.json` contains epoch-end metrics with dropout disabled. Loss includes the L2 penalty once; `metrics.json` also separates out the unregularized `data_loss`.

`model.npz` is an inference checkpoint containing recognized layer configuration and numerical parameters. It does not contain optimizer moments or RNG progression. NPZ checkpoints and downloaded data are present locally but excluded from Git; text results, figures, and CSV files are intended to be committed.

Experiment reports use the same fixed data split for every model seed. Accuracy standard deviations describe variation across three runs; they are not confidence intervals. Training times were measured on a shared machine with other project work running, so they are descriptive, not isolated speed benchmarks.
